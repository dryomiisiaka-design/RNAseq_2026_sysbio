RNAseq_2026_sysbio

RNA-seq analysis workflow developed as part of the **Systems Biology** coursework at **Vilnius University** (Master’s Programme).

This project implements a reproducible RNA-sequencing analysis pipeline using **Snakemake**, covering preprocessing, alignment, quantification, quality control, and differential gene expression analysis.

---
#📚 Project Overview

The aim of this project is to build a fully reproducible RNA-seq workflow following best practices in computational biology.
